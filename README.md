# 华为 eNSP 配置批量生成工具

一个给网络运维/学习用的桌面小工具：把已验证过的华为 eNSP 配置命令固化成模板，
在图形界面上填参数，一键生成可粘贴到设备的配置脚本。纯离线、零第三方依赖。

## 功能

- **接口 VLAN**：access / trunk 批量配置
- **三层网关**：Vlanif 网关接口
- **DHCP**：路由器接口地址池 / 交换机全局地址池
- **VRRP**：主备网关，逐行区分主/备角色
- **MSTP**：根桥实例配置
- **Eth-Trunk**：链路聚合
- **OSPF**：路由宣告
- **ACL**：基本 / 高级 ACL
- **IP / VLAN 库**：常用网段和 VLAN 号保存到本地 `variables.json`（首次使用时自动创建，不入 git），输入框下拉快速选用
- **汇总输出**：自动扫描所有模块用到的 VLAN，生成 `vlan batch` 头部，避免漏建 VLAN
- 生成结果实时预览，支持复制 / 导出 `.cfg`

## 运行

需要 Python 3.12+（仅标准库，无需安装任何依赖）：

```bash
python main.py
```

## 使用说明

1. 左侧"IP / VLAN 库"可预先录入常用网段和 VLAN 号（保存在本地 `variables.json`，不入 git）
2. 顶部页签选择需要的模块，填写参数
3. 底部预览区查看生成的配置，确认无误后复制或导出

## 目录结构

```
├── main.py        # 入口，启动主窗口
├── gui.py         # 界面骨架：左侧库 + 模块页签 + 底部输出预览
├── variables.py   # IP/VLAN 库读写（variables.json）
├── modules/       # 配置生成逻辑（纯函数，参数进、配置字符串出）
├── pages/         # 各模块的表单页面
└── widgets/       # 通用界面控件（端口选择、行编辑器等）
```

## 说明

测试版本，个人运维提效用途。生成的配置粘贴到设备前请自行核对。欢迎按
